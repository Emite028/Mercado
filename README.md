## Sobre o projeto

O Mercado é um projeto de software com foco na organização e no gerenciamento de informações relacionadas às atividades de um estabelecimento comercial.

A proposta é aplicar conceitos de desenvolvimento de software em um cenário que envolve produtos, operações comerciais e organização de dados, conforme o escopo definido na implementação.

Este repositório reúne os arquivos do projeto e serve como base para manutenção, documentação e futuras melhorias.

## Objetivos

- Aplicar conceitos de programação e desenvolvimento de software.
- Organizar o código-fonte de maneira estruturada.
- Desenvolver uma solução relacionada à gestão de um mercado.
- Facilitar a manutenção e a evolução da aplicação.
- Documentar os procedimentos necessários para configurar e executar o sistema.

## Funcionalidades

As funcionalidades devem ser descritas de acordo com a implementação atual do projeto.

Em um sistema de gerenciamento de mercado, podem ser considerados recursos como:

- Cadastro e consulta de produtos.
- Atualização de preços e informações.
- Controle de estoque.
- Registro de vendas.
- Consulta de informações comerciais.
- Organização e gerenciamento de dados.

Os itens acima são possibilidades de desenvolvimento e não representam funcionalidades confirmadas nesta versão.
